# Понемногу

Уютный веб-планировщик на русском языке: задачи, календарь и маленький помощник Пончик. Тестовое задание, созданное с помощью Codex и навыка UI/UX Pro Max.

## Возможности

- Добавление задач с проверкой пустого названия и лимитом 180 символов.
- Отметка выполнения и возврат задачи в работу.
- Удаление с отменой в уведомлении.
- Планирование на дату: календарь, «Сегодня», «Завтра», «Без даты».
- Фильтры: все задачи, сегодня, предстоящие, выполненные и выбранный день.
- Прогресс и реакции Пончика на добавление, завершение, удаление и пустой список.
- Сохранение в localStorage после каждого действия; обновление между вкладками.
- Обработка запрета хранилища, переполнения и повреждённых данных без тихой потери задач.
- Адаптация для телефона, планшета и ПК, клавиатурный календарь и reduced motion.

## Запуск

Нужен Node.js 22 или новее. У приложения **нет npm-зависимостей** и нет API-ключей.

```bash
npm run dev
# http://127.0.0.1:4173

npm test
npm run check
npm run build
```

Папку `dist/` можно разместить на любом статическом хостинге. Все пути относительные: приложение работает и в подкаталоге.

## Clean Architecture

```text
src/
  domain/          # сущность задачи, валидация, даты, фильтры, порт репозитория
  application/     # сценарии add / toggle / remove / restore и транзакция сохранения
  infrastructure/  # адаптер localStorage и формат хранения
  presentation/    # DOM, календарь, персонаж и дизайн-токены
  main.js          # composition root: связывание конкретных зависимостей
```

Зависимости направлены внутрь: `presentation → application → domain`, `infrastructure → domain`. Домен и сценарии не знают о DOM, localStorage, HTTP и конкретном хранилище. Репозиторий, генератор ID и часы внедряются в `TaskService`. Проверка `npm run check` контролирует границы слоёв. Команда `npm test` использует встроенный Node.js test runner.

## Данные и ограничения

Задачи хранятся **только в этом браузере на этом устройстве**, под ключом `ponemnogu.tasks.v1`. Они не отправляются на сервер и не синхронизируются между устройствами. В приватном режиме браузер может удалить их при закрытии окна; очистка данных сайта тоже удалит задачи. Не сохраняйте здесь единственную копию критически важных данных.

Дата — календарный день, а не UTC timestamp. Часовой пояс не сдвигает запланированный день. Уведомлений по времени нет: календарь предназначен для планирования.

При ошибке записи состояние в памяти не меняется. При повреждённом формате приложение сохраняет исходное значение и блокирует изменения. Названия задач выводятся через `textContent`, а не HTML.

## Деплой

В `infra/` находится конфигурация отдельного nginx-контейнера. Сайт раздаёт только содержимое `dist/`; `.git`, исходные настройки сервера, ключи SSH и переменные окружения туда не копируются. Секреты и доступы не должны находиться в этом репозитории.

После сборки можно выполнить `bash scripts/deploy.sh user@host`. Скрипт использует SSH-агент/локальные настройки SSH, создаёт отдельный контейнер `ponemnogu-todo` на порту 8092 и проверяет HTTP-ответ. Другие контейнеры не перезапускаются. Релизы переключаются атомарной ссылкой `current`; при неудачной проверке возвращается предыдущая ссылка, если она существует. Нужны Docker и свободный порт 8092 на сервере. По умолчанию используется HTTP; HTTPS можно настроить на внешнем reverse proxy.

Для публикации исходников используется GitHub. CI запускает тесты, проверку архитектуры и сборку на каждый push/PR. Адрес сервера и способ доступа передаются отдельно от репозитория.
